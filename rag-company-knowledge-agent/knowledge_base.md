# Example Company Knowledge

## Onboarding
New engineers complete security training during their first week. The engineering handbook is the primary source for development standards.

## Development
Pull requests require at least one reviewer. Automated tests should pass before merging.

## Support
Internal technical questions should be posted in the engineering help channel. Urgent production incidents follow the incident-response process.

## Documentation
Product documentation should include setup steps, configuration, common errors, and ownership information.
