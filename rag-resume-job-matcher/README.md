# RAG Resume & Job Matcher

A RAG application that compares a candidate resume with a job description by retrieving relevant resume sections and generating an evidence-based match summary.

## Stack
Python, Sentence Transformers, NumPy, OpenAI, Streamlit

## Features
- Resume section retrieval
- Job-description-aware questions
- Evidence snippets from the resume
- Skill-gap identification
- No-match fallback when evidence is missing

This is a portfolio demonstration; do not use it as an automated hiring decision system.
