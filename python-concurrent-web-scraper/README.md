# Concurrent Python Web Scraper

A learning-focused asynchronous HTTP scraper demonstrating concurrency limits, retries, timeouts, result collection, and clean separation of networking from parsing.

## Stack
Python asyncio + aiohttp

## Run
```bash
pip install -r requirements.txt
python scraper.py
```

Use only websites you are authorized to access and respect their robots.txt, terms, rate limits, and server load.
